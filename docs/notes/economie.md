# Argent, magasins, survie, vente de rue

- **Argent** : sale = objet `cash_dirty` du sac (confiscable), propre = `Player.cleanBalance`. Départ : `economy.startingMoney` = 150 $ propres, 0 $ sale, sans compte. L'argent propre se dépense **sans compte bancaire** ; le compte (`hasAccount`) n'est exigé que pour recevoir de l'argent blanchi (banque, cave). HUD : 💳 solde propre toujours affiché, 💵 espèces en rouge.
- **Monnaies** (`currency` par étagère de `shops.json`, défaut `dirty`, vérifié par zod + `data.ts`) :

  | Monnaie | Payé avec                                                         | Articles                                                                                                                                         |
  | ------- | ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
  | `dirty` | espèces du sac (💵)                                               | armes (plus tard) ; aucune étagère aujourd'hui                                                                                                   |
  | `clean` | solde propre (💳), sans compte                                    | outils (ciseaux), voitures, casino, commerces, téléphone                                                                                         |
  | `any`   | propre si le solde couvre le total `any` + `clean`, sinon espèces | nourriture et boissons de base, matériel de production (pots, étendoirs, tables, lampes), sac à dos ; catégories food/drink/water/furniture/gear |

  Bricoshop : pots, étendoirs, tables, lampes, outils, sac à dos (25 $, rayon « Sacs ») ; **aucune graine, plante ni pochon** : les graines viennent uniquement d'El Jefe (pacte, 4 gratuites). Épicerie : nourriture et boissons. Répartition : `splitCart` (shared/shop.ts), écrite par le serveur dans `Player.cartDirty` / `cartClean`. Paiement `checkout` tout ou rien ; refus « Pas assez d'argent propre », « Pas assez d'argent sale », « Poches pleines » / « Sac plein ». Ancien panier sauvegardé sans monnaie = `dirty`.

- **Magasins** : prix uniquement dans `shops.json`, calculés par le serveur (`Player.cart`, `cartTotal`, `rooms/shop.ts`) ; le panier réserve en rayon, paiement au comptoir tout ou rien, panier rendu en sortant / à la déconnexion / au KO.
- **Survie** : jauges réglées par le serveur depuis `survivalAt` (temps de jeu × `clock.survivalScale` en debug), uniquement pour les joueurs connectés. Ralentissement sous le seuil bas (même facteur dans la prédiction client), KO = perte d'argent sale + réapparition au carton. Aucune logique de survie côté client.
- **Vente de rue** : PNJ simulés par le serveur (`rooms/npcs.ts`), grille `findPath`, positions écrites à `config.npc.broadcastHz`. Demande tirée à l'apparition (`rollDemand`, profils `npcs.json`), prix = `pouchSellPrice` × (1 ± `economy.sale.priceVariance`) × `priceMultiplier` de l'area du PNJ (arrondi une fois), intéressés × `demandRate` (voir `docs/notes/quartiers.md`).
- `sale.open` réserve le PNJ pour un seul joueur jusqu'à la fin de sa patience ; `sale.accept` / `sale.decline`. Verrou levé si le joueur change de zone, se déconnecte ou tombe KO. Cooldown puis nouvelle demande.
- Chaque vente émet `sale_completed` (`SaleCompletedEvent`) sur `room.events` : point d'accroche du Heat et de la police.
- `npm run balance` : rentabilité par cycle / minute, débouché de la rue, coût de la survie en argent propre ($/min, $/h) et pochons à vendre puis blanchir pour le couvrir (`survivalCostReport`).
- **Banque** (`banque` → intérieur `bank`) : courtier = poste `talk` (dialogue `banker` de `dialogues.json`, `rooms/dialogues.ts`, intention `dialogue.choose`, action serveur `open_account`, conditions `account` / `no_account` / `pact` / `no_pact` ; `config.dialogue.requirePact` = true : sans pacte, nœud `no_pact` qui renvoie vers El Jefe). Guichets `teller` : `bank.launder` → `checkLaunder` (shared/bank.ts) : commission `economy.bank.fee` arrondie au dollar supérieur, plafond `launderCap` sur `capWindowSeconds` glissantes (`Player.launderLog`, décalé du temps sans joueur connecté), événement `laundered` (`LaunderedEvent`). HUD : 💳 solde si compte ouvert (sinon —), 💵 espèces sales en rouge.
- **Pacte d'El Jefe** (`repaire_jefe`, lieu sans intérieur : `dialogue` + `actionLabel` dans `locations.json`) : ACTION « Parler à El Jefe » → `Interact` → `DialogueDesk.start` sur le lieu (proximité de la porte, zone rue, revalidées à chaque `dialogue.choose`). Dialogue `el_jefe` : accepter = action serveur `accept_pact` (`economy.pact.startSeeds` × `seedItemId` dans le sac, `Player.pactAccepted`, une fois par joueur ; sac plein = refus, pacte non conclu) ; refuser = relançable ; pacte conclu = nœud `reminder`. `pactAccepted` optionnel dans le snapshot (ancienne sauvegarde = pas de pacte). Pas de taxe sur les ventes pour l'instant (`elJefe.salesTaxRate` inutilisé).
- **Lieux de blanchiment** (`economy.launder.venues`, un plafond glissant et un journal par lieu : `launderLog`, `cellarLaunderLog`, gelés sans joueur connecté) :

  | Lieu     | Accès                                                           | Commission | Plafond | Fenêtre | Compte exigé |
  | -------- | --------------------------------------------------------------- | ---------- | ------- | ------- | ------------ |
  | `bank`   | guichets de la banque (rue centrale)                            | 50 %       | 5000 $  | 30 min  | oui          |
  | `cellar` | blanchisseur de la cave, trappe cachée (jardin du Quartier Sud) | 15 %       | 1500 $  | 30 min  | oui          |

  Commission arrondie au dollar supérieur (`launderSplit`). Le blanchisseur ouvre le panneau par son dialogue (`open_launder`) ; tout poste avec `launderVenue` (ou un guichet `teller` = banque) blanchit. Événement `laundered` : `venue` et `area` (pour la Heat). `npm run balance` compare banque seule, cave seule et combinaison (`launderReport`).

- **Capacité du sac** (`economy.bag`) : départ en poches (`pocketSlots` = 6, `Player.bagTier` 0) ; le sac à dos (`backpackItemId`, Bricoshop, 25 $ « any ») s'utilise depuis l'inventaire (bouton « Utiliser », `use.action` `equip_bag`) : objet consommé (porté, plus jamais déposable ni vendable), `bagTier` 1, `backpackSlots` = 12 cases ; double équipement refusé. La taille du sac est celle de `Player.bag` (jamais une constante) ; tant que `bagTier` = 0, l'inventaire montre les cases manquantes grisées avec cadenas. Plus de place : `bagFullText(bagTier, détail)` (shared/bag.ts), seule source du texte : « Poches pleines : … » sans sac à dos, « Sac plein : … » avec (achat, pacte, vente de rue, récolte, décrochage, reprise de meuble, fin de découpe). Sauvegarde : `bagTier` optionnel ; absent (partie à 10 cases), il vaut 1 si les piles dépassent les poches, sinon 0 et les piles sont tassées dans 6 cases (`bagTierFor`, `fitBag` : aucun objet perdu). Debug : sac à dos, palier forcé, sac vidé. `npm run balance` : cases occupées au départ et délai avant le sac à dos. Au départ (sans espèces), kit + 4 graines = 4 cases sur 6.
