# Décor 3D importé (modèles de décor)

- **Source** : packs bruts dans `public/maps/3D/` à la racine (hors dépôt, `/public/` ignoré). Packs Kenney (Car Kit, City Kit Commercial / Industrial / Suburban, Coaster Kit, Nature Kit), licence CC0 déduite des noms des packs, **à confirmer** (`props.json` `license`). Seuls les fichiers allégés de `client/public/models/<catégorie>/` sont commités. Catégories : `batiments`, `vehicules`, `props`, `vegetation`.
- **Inventaire** : `npm run models -- --props public/maps/3D` classe chaque fichier d'après son nom (`?` = douteux : montagnes russes, kit d'intérieur de supérette, pièces détachées, karts et tracteurs, tuiles de terrain, décor nature hors thème) et donne triangles, draw calls après fusion, textures, poids, boîte, origine, budget. Sans dossier : contrôle des modèles de `props.json` (code 1 si hors budget).
- **Budget** (`config.props.budget`) : bâtiment < 3 000 triangles, véhicule et prop < 1 000, végétation < 500 ; 1 texture de 1024 px au plus, < 1 Mo par fichier, < 30 Mo au total (`maxTotalMB`). Pas de modèle de lampadaire dans les packs : les lampadaires restent générés.
- **Import** (`npm run models:import`, `scripts/import-props.ts`) : lit `scripts/props-selection.json` (id, fichier source, catégorie, hauteur réelle en m, rotation corrective, `collision` `rect` / `circle` / `none`, `cuttable`, `keepColors` / `tint`, tags). Toutes les primitives fusionnées en une seule, texture remplacée par une couleur par face (prise au centre des UV, sRGB → linéaire), GLB minimal (POSITION + COLOR_0 en octets). Au-delà du budget : simplification (SimplifyModifier, dichotomie), refusée sous `minKeepRatio` (écarté, signalé). Écrit `shared/data/props.json` : boîte du fichier, décalage qui ramène le pied centré à l'origine, collision dérivée de la boîte (cercle de `vegetationCollisionRatio` pour un arbre), jamais le maillage.
- **Ajouter un modèle** : 1. copier le pack dans `public/maps/3D/` ; 2. `npm run models -- --props <dossier>` pour le budget et la boîte ; 3. ajouter une entrée dans `scripts/props-selection.json` (avant du modèle vers +Z, sinon `rotationY`) ; 4. `npm run models:import` ; 5. l'utiliser dans `shared/data/placements.json` ; 6. `npm test` (budget, cohérence, collisions, draw calls par area).
- **Placements** (`shared/data/placements.json`) : `kits` remplace un décor généré (`trees`, `palms`, `cars`, `policeCars`, `houses`, `towers`, `fillers`) par une liste de props tirés en alternance ; liste vide = générateur actuel. Ajustement `height` (hauteur réelle × échelle générée), `length` (longueur de `decor.carSize`), `box` (emprise générée, hauteur × `heightScale`) : l'emprise ne change pas, donc collisions et trajets non plus. Les générateurs sautent alors la façade (`buildQuartiers`, `buildFiller`) ; enseignes des tours, lieux, intérieurs, portes et points d'interaction inchangés. `areas` pose des props à la main (quart de tour seulement) : bâtiments décoratifs sans bouton ACTION (ce ne sont pas des lieux).
- **Collisions** : boîtes de `props.json` dans `obstaclesFrom` (joueurs, prédiction, PNJ, grille de navigation). `checkPlacements` (shared/props.ts, au chargement) refuse un prop hors de son area, sur une route, un trottoir ou une placette d'impasse, à moins de `doorClearance` d'une porte, sur un obstacle, ou créant une fente plus étroite qu'un diamètre + marge. Tests : tous les lieux atteignables depuis le départ, trajets comparés avec et sans props (détour > 2 m signalé).
- **Textures** : depuis le rendu de référence, l'import garde les UV et copie l'atlas du pack (`models/textures/<pack>.png`, ≤ 1024 px, < 30 Mo en mémoire, test) ; seuls les modèles sans texture (Nature Kit) gardent des couleurs de sommets.
- **Rendu** (`client/src/game/city/propAssets.ts`, `PropKits.tsx`, `propPlacements.ts`) : chargement par id avec cache, seulement quand une area de ses instances est chargée ; géométrie normalisée (pied à 0, avant +Z, hauteur réelle). 1 `InstancedMesh` par id (1 draw call), matériaux de la fabrique (`decorSolid`, ou `propCut` avec découpe pour les bâtiments, `aCut` = 1). `keepColors` faux : couleurs mêlées à la teinte de palette (`tintStrength`). Échec de chargement ou de rendu : cube neutre (`fallbackColor`), journalisé, error boundary par prop. Ombres blob : celles des kits générés remplacés sont gardées.
- **Draw calls** (scène montée avec les vrais GLB, `sceneBudget.test.ts`, par excès, thèmes day, cartel, neutral, legacy_night) : jour bas-fonds 52, chez nous 52, centre-ville 58, commercial 55, cartel 44 ; objectif `config.props.drawCallTarget` (62 ; le centre-ville charge les bas-fonds et l'aéroport voisins), plafond `drawCallBudget` (200). Overlay `?debug=1` : draw calls max par thème/area et du décor 3D par catégorie (`batiments`, `vehicules`, `avions`, `props`, `vegetation`). `sceneMount.test.ts` : chaque area, 120 ticks, rendus bornés, repli cube d'un modèle en échec.
- **Props posés fusionnés** (`mergedPropIds`, `MergedProps` dans `PropKits.tsx`) : un prop posé seulement à la main (`placements.areas`, ni kit ni façade), sans atlas, ni découpe, ni néon, est fusionné avec les autres en un seul Mesh (1 draw call pour tous), reconstruit quand les areas chargées changent. Un prop texturé ou partagé avec un kit garde son InstancedMesh. Les façades importées sans atlas (`mergedFacadeIds`) sont fusionnées de même dans un second Mesh (`facades_fusionnees`, découpe et néons) : une nouvelle façade ne coûte un draw call que dans une area où aucune autre n'est chargée.
- **Plusieurs props dans un même `.glb`** : `node` dans `scripts/props-selection.json` (nom de l'objet racine dans Blender) n'importe que ce nœud ; boîte, pied et collision sont ceux du nœud.
- **Bâtiments de quartier** (`models/quartier/`, famille `corner` d'angle ou `row` de rangée) : modélisés dans Blender (`public/models/quartier-narcos/quartier.blend`, hors dépôt ; scripts dans les blocs texte `qn_*`), 1 m = 1 unité, pied centré à l'origine, façade vers +Z (angle coupé du coin vers +X/+Z), matériaux unis nommés sans texture, néons en matériaux émissifs.
- **Ajouter un bâtiment d'angle ou de rangée** : 1. exporter le `.glb` (Y vers le haut) dans `public/models/quartier-narcos/` ; 2. entrée dans `scripts/props-selection.json` avec `sourceDir` (dossier du `.glb`), `folder: "quartier"`, `category: "batiments"`, `family`, `footprint` (`{w, d}` : 10 × 10 pour un coin, 8 × 8 pour une rangée), `height` (hauteur de la boîte, échelle 1), `rotationY: 0`, `cuttable: true` ; 3. `npm run models:import` (fusion en 1 primitive, couleurs des matériaux gardées) ; 4. le poser dans `placements.json` `areas` (quart de tour) et `npm test`. `data.ts` refuse une famille sans emprise, hors `batiments` ou dont la collision déborde de l'emprise.
- **Néons des modèles** : un matériau à `emissiveFactor` non nul devient une couleur de sommet = couleur émise et l'attribut `_EMISSIVE` (1 par sommet de néon) du GLB ; `props.json` `emissive: true`. Au rendu, `aEmit` et `applyEmission` (`materials.ts`) ajoutent couleur × `props.json` `emissive.strength` à l'émission, dans le même draw call. `emissive.enabled: false` (réglé dans `scripts/props-selection.json`, recopié à l'import) éclaire les néons comme le reste.
- **Remplacer la façade d'un lieu** (exemple : épicerie, `public/models/shops/epicerie/epicerie.blend`, hors dépôt, collections « Batiment » et « Props ») : le modèle ne change que l'aspect extérieur ; id, position, taille, porte, point d'interaction, intérieur et collision (rectangle du lieu) restent ceux de `locations.json`.
  1. Modéliser dans Blender : 1 m = 1 unité, pied centré à l'origine, porte vers −Y de Blender (+Z du glTF), tout (auvent compris) dans la taille du lieu (`size.w` le long de X, `size.d` en profondeur), < 3 000 triangles, matériaux unis nommés, enseigne et néons émissifs. Props au sol à part (< 1 000 triangles chacun), un objet racine par prop.
  2. Exporter en `.glb` (Y vers le haut) : `<lieu>_batiment.glb` (collection Batiment) et `<lieu>_props.glb` (collection Props).
  3. `scripts/props-selection.json` : bâtiment `family: "facade"`, `footprint` = taille du lieu (`{w, d}`, côté porte = `w`), `folder: "shops"`, `category: "batiments"`, `height` = hauteur de la boîte, `cuttable: true` ; un prop par nœud (`node`, `category: "props"`). Puis `npm run models:import`.
  4. `placements.json` `facades` : `"<id du lieu>": "<id du bâtiment>"`. Le modèle est posé au centre du lieu, avant tourné vers `door` (sud 0°, est 90°, nord 180°, ouest 270°) ; la silhouette générée (`buildCity`) et le panneau peint (`panelSpots`) sont sautés ; étiquette, halo, mini-carte, brouillard, ombre et intérieur inchangés. `checkFacades` (au chargement) refuse un lieu inconnu, caché ou sans porte, un prop hors famille `facade`, une emprise ou une collision plus grande que le lieu.
  5. Props au sol dans `placements.json` `areas` : devant la façade, hors du rectangle du lieu, à `doorClearance` du point d'interaction, collés au lieu ou entre eux (une fente plus étroite qu'un diamètre + marge est refusée).
  6. `npm run check`, `npm run collisions` (0 problème), draw calls de `sceneBudget.test.ts`.
- **Banque** (`public/models/banque/banque.blend`, hors dépôt, script dans le bloc texte `bq_build`, collections « Batiment » et « Props ») : temple néoclassique d'après `image.jpg` (6 colonnes, fronton, escalier, verrière), 2 070 triangles, 8 × 10 × 8,94 m, pierre / brique / socle, enseigne BANK et $ émissives. Props au sol (distributeur, bacs à arbuste, boîte aux lettres, panneau, haie) de part et d'autre de l'escalier, à plus de `doorClearance` de la porte.
- **Commissariat** (`public/models/police/police.blend`, hors dépôt, script dans le bloc texte `pd_build`, collections « Batiment » et « Props ») : d’après `police.jpg` (briques sombres, pilastres et corniche en pierre, perron, verrière, enseignes POLICE et PD émissives), élargi à l’emprise du bloc décoratif `se_fond` (30 × 12 × 10,6 m, 2 022 triangles). `facades` accepte un bloc à porte (sans interaction) : silhouette et panneau peint générés sautés ; étiquette, icône, halos (enseigne, gyrophares du toit) et voitures de police inchangés. Props (barrière, panneau, mât de drapeau, bacs) collés à la façade nord, dans le draw call fusionné.
- **Tours modélisées** (`models/tours/`, `public/models/bulding/bulding.blend`, hors dépôt) : beige à gradins (`tour_beige`, 10 × 11 × 26 m), brique (`tour_brique`, 10 × 8 × 27 m, large et peu profonde), bureaux vitrés (`tour_verre`, 10 × 11 × 26 m, escalier de secours) ; un objet racine par tour dans `bulding_batiment.glb` (`node`). Elles remplacent `skyscraper_a/b/e` dans `kits.towers` (budget constant) : `fitBox` choisit pour chaque tour générée le modèle aux proportions les plus proches (beige 6, verre 5, Kenney 5, brique 2 sur les îlots larges). Props au sol (bac à arbuste, borne d'incendie, boîtes aux lettres) posés autour de `nw_ouest`, dans le draw call fusionné.
- **Ajouter une tour au kit sans coût** : en remplacer une (chaque id visible = 1 draw call dans l'area et ses voisines) ; proportions largeur / profondeur distinctes des autres pour qu'elle soit retenue, hauteur native proche de 25 m (l'échelle verticale suit l'emprise, à ± `maxStretch`).
- **Assemblage de la map** (modèles fournis, `public/models/<dossier>/`, hors dépôt ; image de référence `public/models/maps/maps.jpg`) : fichiers allégés dans `client/public/models/{shops,aeroport,avions,voitures,objets}/`. Rien n'a bougé : façades (`placements.facades`) Local → `labo_batiment` (tel quel), `co_ouest` → laverie (échelle 0,95), `co_milieu` → armurerie, `co_est` → barbier, `co_bras_milieu` → concession ; supérette CORNER MART posée dans `areas.commercial` (angle coupé −X/+Z du modèle vers la rue) ; Bricoshop et caisses restent générés.
- **Groupes de props d'un bâtiment** (`*_props`, `*_props_a/_b`) : `nodes` (nœuds retenus, préfixe) ou `exclude` (dalles `Trottoir`, `Parvis`, `Gazon`), `keepOrigin: true` (origine du fichier = centre du bâtiment), `collision: "none"` ; posés dans `placements.areas` au centre de l'hôte, même rotation et échelle. Coupés en deux fichiers sous le budget `props` (1 000 triangles) ; intérieurs (laveuses, fauteuil, rayons) écartés car les vitrines sont opaques.
- **Vitrines** : tout matériau `alphaMode: BLEND` devient opaque de la couleur `glass` de `scripts/props-selection.json` (bleu sombre).
- **Voitures** : `paint: "carrosserie"` dans la sélection → carrosserie blanche + attribut `_PAINT` ; au rendu `aPaint` et `applyPaint` (`materials.ts`) mêlent la couleur d'instance (`config.props.paints`, palette × facteur, en alternance) dans le même draw call. Police : livrée gardée (pas de `paint`). Fourgon, camion, camionnette, muscle et SUV de police importés mais hors kits (draw calls ; `decor.carSize` ramènerait un camion à 4,2 m).
- **Aéroport** : `kits.planes` (fit `contain` : taille réelle, réduite à l'emprise générée), `kits.hangars` (`alternate`, porte côté piste comme le hangar généré) ; `merge: true` les fond dans les Mesh fusionnés. Props du hangar posés sans collision.
- **Objets de la ville** : `kits.lamps` (crosse, rues), `kits.quartierLamps` (lanterne, impasses), `kits.bins`, `kits.trees` remplacent le décor généré aux mêmes positions (halos gardés). Le reste est semé par `scatterPlacements` (`shared/src/streetFurniture.ts`) : le long de chaque côté de route (et du bord extérieur des trottoirs d'impasse), avant vers la route, pied à `curbInset` du bord ; ajouté aux props posés au chargement (`data.ts`), donc mêmes collisions, vérifications et rendu fusionné.
- **Régler la densité** : `config.props.scatter.areas.<area>` : `spacing` (m entre deux objets, plus grand = moins dense), `props` (alternance), `corner` (premier objet après un croisement). Draw calls au-delà de l'objectif : augmenter `spacing` ou retirer un prop à néons, jamais relever `drawCallTarget`. Puis `npm test` (draw calls, collisions, trajets).
- **Remplacer un modèle** : exporter le nouveau `.glb` à la place de l'ancien (même nom, avant +Z, pied à l'origine), `npm run models:import`, `npm run check`, `npm run collisions` ; un id renommé se change dans `placements.json` (kit, façade ou pose) ou `config.props.scatter`.
